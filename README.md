# Sri Lankan Food Price Forecasting — CM4371 Ensemble Learning Dashboard

**Task:** Use Sri Lankan WFP/HDX retail food-price data to predict the following month's market–commodity price and compare bagging, boosting, stacking, and optional hybrid methods.

**Dataset period:** January 2023–September 2025. **Held-out test:** April–September 2025 (six consecutive months). **Explorer forecast:** October 2025, immediately after the dataset ends. This is a **historical forecast, not a live/current price**.

## Models

- **Baseline:** last month's observed price (naive), national ARIMA, Ridge
- **Bagging:** Random Forest
- **Boosting:** Gradient Boosting (GBM), XGBoost, CatBoost
- **Stacking:** forward-chaining base-model predictions with a nonnegative Ridge meta-model
- **Hybrids (additional exploration):** RF + national ARIMA residual model; RF + ANN average

All models target the **one-month log-price change**; error metrics are calculated on prices in **LKR per the commodity's reported selling unit** (mainly KG; some items are sold per Unit). Since food items are sold in different units (such as kilograms or individual items), the overall MAE is reported in LKR per prediction, rather than LKR/kg for every food item.

## Run on your computer

1. Install **Python 3.13** (the trained model files were generated using Python 3.13 and the package versions in `requirements.txt`).
2. Open a terminal in this project folder. Create an environment and install requirements:

   ```bash
   python -m venv .venv
   source .venv/bin/activate           # macOS / Linux
   # .venv\\Scripts\\activate           # Windows PowerShell: .venv\\Scripts\\Activate.ps1
   python -m pip install -r requirements.txt
   ```
3. **To inspect the already-run assignment:** open `Food_Price_Ensemble_Learning.ipynb` in Jupyter/VS Code. Its saved cells include the model results, plots and discussion. You can execute all cells if you want to independently reproduce the results.
4. **To run the dashboard:**

   ```bash
   streamlit run app.py
   ```

   The dashboard reads the included **trained** `models/models.joblib` and all saved result files; you do not need to retrain to launch it.

5. **To retrain:** run every notebook cell top-to-bottom **from this directory**, with `foodprice.py` next to the notebook. The notebook creates `figs/` and updates all of `models/` together.

6. Optionally run `python validate_project.py` for a quick integrity check of the supplied models and result tables.

## Methodology and limitations

- Train on the past; test on the **last six observed months**. The one-step predictions in the test period can use the actual prices from prior test months, but never the price from the forecast month or later.
- **Leakage fix:** no future-dependent interpolation. Missing month–commodity observations are left missing, and samples requiring unavailable lagged observations are excluded. National ARIMA uses only historical observations.
- Global test MAE improvement is the **observation-weighted** mean. A separate average over market–commodity series is reported and explicitly labelled as such.
- The reported bootstrap interval resamples the **six test months** as exploratory blocks rather than treating market–commodity observations as independent. Six months are too few for strong statistical confidence.
- Missing months reduce coverage. Models were not exhaustively tuned. There is no live data feed, and this project does not claim October 2025 forecasts are current prices.

## Data source

World Food Programme (WFP), *Sri Lanka Food Prices* dataset, via Humanitarian Data Exchange (HDX). The original downloaded CSV is included under `data/`. The source fields include `date`, `market`, `commodity`, `unit`, `pricetype` and `price`.
